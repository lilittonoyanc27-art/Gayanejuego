# Gayane: Pet Shop Adventure — Mundo Animal

Образовательная 3D-игра для изучения испанского (A2–B2). Весь интерфейс на испанском, армянский перевод открывается по клику, русского внутри игры нет.

## Запуск

Нужен Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Проверка типов и сборка: `npm run build`. Проверка содержания (переводы, ветки диалогов, выполнимость миссий): `npm run check:content`.

## Публикация

1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. На vercel.com выберите **Add New → Project**, укажите репозиторий и нажмите **Deploy**. Настройки уже заданы в `vercel.json`.

## Управление

| | Компьютер | Телефон / планшет |
|---|---|---|
| Ходить | WASD или стрелки (Shift — быстрее) | джойстик слева |
| Смотреть | перетаскивание мышью, Q | перетаскивание пальцем |
| Взаимодействовать | E или клик | кнопка «Interactuar» |
| Вид от 3-го лица | V | кнопка «Ver a Gayane» |
| Быстрый переход в отдел | клик по мини-карте | касание мини-карты |

Перевод: клик по тексту; на кнопках — буква **Ա**, правый клик или режим перевода (круглая кнопка **Ա**).

## Структура

- `src/data` — тексты: диалоги, миссии, клиника, истории, грамматика, скороговорки, игры. Формат: `español|հայերեն`.
- `src/core` — сохранение, озвучка, звуки, словарь.
- `src/three` — 3D: животные, персонажи, товары, магазин.
- `src/modes` — режимы игры. `src/ui` — общие компоненты.

## Особенности

- Прогресс хранится в `localStorage` этого браузера.
- Озвучка использует испанские голоса системы; лучше всего Chrome, Edge или Safari с установленным голосом es-ES.
- Проверка произношения микрофоном работает там, где браузер поддерживает распознавание речи (Chrome, Edge, Safari).
- Все модели и звуки создаются кодом, внешние файлы не загружаются. Графика подстраивается под мощность устройства; режим «modo rápido» есть в настройках.
